## Agent skills

### Issue tracker

GitHub Issues in `S1NXIAN/mhp3rd-save-editor` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Defaults: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: read `GLOSSARY.md` and `docs/adr/` when present. See `docs/agents/domain.md`.

### Documentation standards

Any edit to agent-facing docs (`AGENTS.md`, `docs/`, extension `README.md`) MUST follow [`AGENT_DOCS_STANDARD.md`](./AGENT_DOCS_STANDARD.md).

### Coding standards

Any code change MUST follow [`CODING_STANDARD.md`](./CODING_STANDARD.md).
