This project contains a Python port of the save-format offsets and cipher
tables from:

  erickdevit/savemud
  https://github.com/erickdevit/savemud
  MIT License

The underlying Monster Hunter PSP save cipher was documented by:

  svanheulen/mhef
  https://github.com/svanheulen/mhef
  GPL-3.0

The AES layer is performed by the system `openssl` command; no AES code is
bundled here.
